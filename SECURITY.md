# Security Policy / Güvenlik Politikası

## Türkçe

Güvenlik açıklarını herkese açık issue içinde paylaşmayın. Depo sahibine GitHub üzerinden özel güvenlik bildirimi gönderin. Bildirimde etkilenen alanı, yeniden üretme adımlarını ve olası etkisini belirtin; gerçek hasta, çalışan veya kurum verisi eklemeyin.

Desteklenen sürüm, canlı sitede yayımlanan en güncel ana sürümdür. Bu proje portföy ve kontrollü pilot niteliğindedir; bağımsız güvenlik incelemesinden geçmiş sertifikalı bir hastane bilgi sistemi olarak sunulmaz.

## English

Do not disclose vulnerabilities in a public issue. Use GitHub's private security reporting channel for the repository owner. Include the affected component, reproducible steps and potential impact, but never attach real patient, employee or organization data.

Only the latest main version represented by the live deployment is supported. This is a portfolio and controlled-pilot project; it is not presented as a certified hospital information system or as having passed an independent security audit.
