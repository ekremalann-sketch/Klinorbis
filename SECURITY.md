# Security Policy / Güvenlik Politikası

## Türkçe

Güvenlik açıklarını herkese açık issue içinde paylaşmayın. Depo sahibine GitHub üzerinden özel güvenlik bildirimi gönderin. Bildirimde etkilenen alanı, yeniden üretme adımlarını ve olası etkisini belirtin; gerçek hasta, çalışan veya kurum verisi eklemeyin.

İnceleme kapsamı GitHub `main` kaynak kodu ile Sites canlı yayını için ayrı ayrı belirlenir; bu iki kaynak her zaman aynı commit değildir. Bu proje portföy ve kontrollü pilot niteliğindedir; bağımsız güvenlik incelemesinden geçmiş sertifikalı bir hastane bilgi sistemi olarak sunulmaz. Güvenlik durum API'sindeki kontroller, canlı olarak doğrulanmadıkça doğrulanmış sayılmaz.

## English

Do not disclose vulnerabilities in a public issue. Use GitHub's private security reporting channel for the repository owner. Include the affected component, reproducible steps and potential impact, but never attach real patient, employee or organization data.

The GitHub `main` source and the Sites live deployment are tracked separately and may have different commits. This is a portfolio and controlled-pilot project; it is not presented as a certified hospital information system or as having passed an independent security audit. Controls in the status API remain unverified until tested in the live environment.
